Questions

Le prix, les délais, le code.

Combien coûte une app ou un outil sur mesure ?

Ça dépend de ce qu’on construit : un prototype n’a rien à voir avec un logiciel complet. Après un premier échange, vous recevez une proposition écrite, avec le montant et le délai, avant de commencer.

En combien de temps mon produit peut-il être prêt ?

Le délai est écrit dans la proposition, après le cadrage. Les agents IA vont vite, mais chaque étape est relue. Pour repère, le prototype jouable de Booply a pris 4 jours.

Qu’attendez-vous de moi pendant le projet ?

Une personne qui décide, un premier échange pour cadrer, puis des retours rapides sur les maquettes et les versions à tester.

Un code écrit avec l’IA est-il fiable ?

Les agents écrivent et testent, mais rien ne part sans relecture. Je vérifie chaque étape, les tests tournent avant chaque mise en ligne, et le code reste lisible par un autre développeur.

À qui appartiennent le code et le produit ?

À vous. Le code, les comptes, les maquettes et les accès sont à votre nom.

Que se passe-t-il après la mise en ligne ?

Je reste là pour corriger et faire évoluer le produit. Ou je forme votre équipe pour qu’elle le fasse vivre.

Pouvez-vous travailler avec mon équipe technique ?

Oui, avec vos développeurs ou votre prestataire. Et s’il n’y en a pas, je m’occupe de tout.
